# VoidCheatSheet

**In-game cheat sheets for every Midnight raid, the full Mythic+ pool, and delve bosses — auto-pops on pull.**

A hand-curated, role-aware boss strategy panel: mechanics, phase breakdowns, dangerous trash, and Tank/Healer/DPS tips with your role highlighted. No theorycrafting required — pull the boss and read.

---

## Features

### Coverage — 96 encounters
- **17 raid bosses** across 4 raids — **The Venomous Abyss** (Season 2), plus Voidspire, Dreamrift, and March on Quel'Danas
- **57 dungeon bosses** across 16 dungeons — the full **Season 2 Mythic+ pool** (Altar of Fangs, Murder Row, Den of Nalorakk, The Blinding Vale, Voidscar Arena, Kings' Rest, Ruby Life Pools, Temple of Sethraliss) plus the Season 1 pool
- **22 delve bosses** across 14 delves — including Season 2's **Venomfall Deeps** Nemesis (Azta'rec), **The Ring of Glory**, **Gnarldor Isle**, and the "Children of Ula'tek" story bosses
- **Kept current with hotfixes** — strategies re-checked against live guides and Blizzard's hotfix notes

### Every boss page
- **Every ability** — what it does and what to do about it
- **Phase breakdowns**, positioning tips, and common wipe causes
- **Role tips** for Tank, Healer, and DPS — **your role is highlighted**
- **Bloodlust timing** and **tank swap** callouts
- **Heroic/Mythic differences** for raids, **Tyrannical notes** and **dangerous trash** for dungeons, **companion tips** for delves

### Auto-popup
- **Pull any boss** — a compact card pops up with the TL;DR and your role tip
- **Target a delve boss** — the same card appears before the pull
- **Click the card** for the full cheat sheet; **Shift-drag** it to move it anywhere (position is remembered)

### Handy extras
- **Share** a boss TL;DR and tips to party/raid chat with one click
- **Kill tracking** — bosses you've already killed this lockout are marked
- Resizable, draggable, scrollable panel; browse by raid, dungeon, delve, or boss name

## Slash Commands

| Command | What it does |
|---|---|
| `/cs` | Show the full content list (raids, dungeons, delves) |
| `/cs venomous` | Show all Venomous Abyss bosses |
| `/cs ulatek` | Show one boss (works without the apostrophe) |
| `/cs voidspire` | Show all Voidspire bosses |
| `/cs magisters` | Show the Magisters' Terrace dungeon guide |
| `/cs share` | Post the current boss TL;DR and tips to party/raid chat |
| `/cs killed` | List bosses killed this lockout |
| `/cs popup on` / `off` | Turn the auto-popup on or off |
| `/cs hide` | Close the panel |
| `/cs reset` | Reset position and size |

## Getting Started

1. Install with the CurseForge app, or copy the `VoidCheatSheet` folder into `World of Warcraft/_retail_/Interface/AddOns/`.
2. Restart WoW or `/reload`.
3. Pull a boss — or type `/cs` to browse everything.

## Where the Strategies Come From

Every claim is cross-checked against at least two independent guides where possible, then re-checked against Blizzard's official hotfix notes:
- [Wowhead](https://www.wowhead.com) dungeon, raid, and delve guides
- [Icy Veins](https://www.icy-veins.com) boss strategy guides
- [Method.gg](https://www.method.gg) raid, M+, and delve guides
- Blizzard's official hotfix posts

Anything only one guide documents so far is flagged on its page.

## Privacy & Safety

- **Display-only** — shows static boss data; never changes game state
- **No network access** — no web calls, no telemetry
- **Reads nothing personal** — no gold, characters, or account info
- **Open source** — every line is on GitHub
